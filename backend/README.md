# GreatDay

GreatDay is a recommendation application built with **Python, FastAPI, and PostgreSQL**. 

## Features

- Create, view, update, and delete recommendations
- RESTful API
- Request and input validation
- PostgreSQL database integration
- FastAPI backend
- Structured API routes and services

## Tech Stack

- **Python**
- **FastAPI**
- **PostgreSQL**
- **Pydantic**
- **SQLAlchemy**
